# 🌸 Panduan Deploy Google Apps Script Menjadi Web App Layar Penuh (Full Screen)

Jika tampilan sidebar di samping Google Sheets terasa terlalu sempit/kecil, Anda memiliki **2 Pilihan Tampilan Layar Lebar**:
1. **🌐 Opsi 1 (Paling Disukai): Deploy Menjadi Web App Mandiri (Buka di Tab Browser Penuh)**.
2. **🖥️ Opsi 2: Buka sebagai Dialog Layar Penuh (Lebar 1000px) di dalam Google Sheets**.

---

## 🌐 Cara Deploy Menjadi Web App Mandiri (Tab Browser Penuh):

### 1. Buka Editor Apps Script
- Di Google Sheets, klik **Ekstensi** (*Extensions*) ➔ **Apps Script**.
- Pastikan kode di **`Code.gs`** dan **`Sidebar.html`** sudah diperbarui dengan kode terbaru.

### 2. Klik Tombol Deploy
1. Di pojok kanan atas editor Apps Script, klik tombol biru **Terapkan** (*Deploy*).
2. Pilih **Penerapan Baru** (*New Deployment*).
3. Di samping tulisan "Pilih jenis" (*Select type*), klik ikon **⚙️ (Gerigi)** ➔ Pilih **Aplikasi Web** (*Web App*).

### 3. Isi Pengaturan Deployment:
- **Deskripsi**: `Admin Portal Srikandi Bali`
- **Jalankan sebagai (*Execute as*)**: `Saya (email Anda)`
- **Yang memiliki akses (*Who has access*)**: `Siapa saja (*Anyone*)` atau `Hanya saya (*Only myself*)`
- Klik tombol biru **Terapkan** (*Deploy*).

### 4. Buka & Simpan Link Web App Anda!
- Salin (*Copy*) **URL Aplikasi Web** yang muncul (format link: `https://script.google.com/macros/s/.../exec`).
- Buka link tersebut di tab browser baru Anda atau bookmark di browser.
- **Hasilnya**: Anda sekarang memiliki Portal Admin Srikandi Bali Full Screen yang luas, responsif, elegan, dan sangat nyaman digunakan!

---

## 🖥️ Opsi 2: Buka Dialog Lebar (1000px) di Dalam Google Sheets
Jika Anda ingin tetap berada di dalam Google Sheets tetapi dengan tampilan dialog yang luas:
1. Di Google Sheets Anda, klik menu toolbar atas:
   **`🌸 Srikandi Bali Admin`** ➔ **`🖥️ 1. Buka Panel Admin Layar Penuh (Dialog Besar)`**.
2. Jendela formulir dan verifikasi donatur selebar **1000px** akan langsung muncul di tengah layar!
